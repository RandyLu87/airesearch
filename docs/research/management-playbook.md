# 管理层与资本配置手册

治理评价最容易退化成两句话：管理层持股高、创始人在位。这两条都是横截面事实，而管理层质量只能纵向观察——**说过的话有没有做到，赚到的钱配置得怎么样**。

本文件是承诺台账 `research/companies/<company-id>/commitments.json` 的录入方法。台账的契约与物化规则见 ADR-0019 与 `docs/research/analysis-template.md`；这里只讲怎么判断什么该录、状态怎么定。

## 目录

1. 什么算一条可录入的承诺
2. 从哪里提取
3. 结算判定
4. 资本配置逐笔复盘
5. 不做的事

## 1. 什么算一条可录入的承诺

判据只有一条：**到期时能被公开信息判定为做到或没做到。**

| 可录入 | 不可录入 |
| --- | --- |
| 「2026 年内 X 业务实现单季盈利」 | 「我们对 X 业务的长期前景充满信心」 |
| 「未来 12 个月回购不低于 30 亿港元」 | 「会持续提升股东回报」 |
| 「明年资本开支较今年下降」 | 「保持资本开支纪律」 |
| 「Q3 前完成该收购的交割」 | 「积极寻找并购机会」 |

不可判定的表态不录。录进去只会稀释分母，让台账变成一份可以靠挑选条目操纵的东西。

`dueBy` 允许写 `未给时限`——没给时限本身是信息，且这类承诺长期挂着 `待到期` 状态就是它应有的呈现方式。不要替管理层补一个时限。

`quote` 必须是原文摘录，不转述。转述会不知不觉给承诺加上或去掉限定词，而限定词恰恰是结算时唯一要看的东西。

## 2. 从哪里提取

各市场的具体取证入口登记在 `docs/research/data-source-registry.md` 第 10 节。按可引用性排序，与 `docs/research/sources-and-priority.md` 的原则一致：

1. **年报与中报的管理层讨论、董事长/CEO 致股东信** —— 书面、经审核流程、最不容易赖账；
2. **业绩发布会与电话会记录** —— 承诺密度最高的地方，也是提取成本最高的地方；
3. **交易所公告** —— 回购授权、股份计划、重大交易的承诺条款；
4. **公开采访与管理层公开发言** —— 可录，但必须能给出可访问链接；转述二手报道不录。

首次建账覆盖最近三年。三年是回购周期、并购整合和新业务投入初步见效的最短窗口，短于三年的台账几乎全是 `待到期`，产生不了任何判断。

只覆盖到部分年份时，在台账里写明覆盖起始时点。**「这段时间没有承诺」和「这段时间没查」必须能区分**——这是空台账也要显式存在的原因。

## 3. 结算判定

五个状态，`outcome` 必须写结算依据并附证据，只写状态字不合格。

| 状态 | 判定 |
| --- | --- |
| `兑现` | 到期时目标达成，且口径与承诺当时一致 |
| `部分兑现` | 方向对但幅度或时点不足；写清差多少 |
| `未兑现` | 到期未达成 |
| `待到期` | 未到期，或未给时限且尚无结论 |
| `已撤回` | 管理层明确改口或放弃；记下改口的场合与理由 |

**口径漂移按未兑现处理。** 承诺「实现单季盈利」而实际用调整后利润宣布盈利，是没兑现加一次口径变更，不是兑现——把它记成兑现，等于承认换口径可以完成承诺。

**已撤回不等于失信。** 环境变了主动改口，比硬撑到底更值得信任；关键看有没有说明理由。`outcome` 要写清是主动说明还是悄悄不提了。

**不追溯改写。** 发行人事后重述指引时，新增一条并在 `outcome` 里指明它替换了哪一条。ADR-0002 的不可覆盖原则对管理层说过的话同样适用。

## 4. 资本配置逐笔复盘

每笔并购、回购、分红、新业务投入各录一条，都要留下**当时的判断依据**，否则事后只能凭结果反推，而结果里混着运气。

**回购**：记录金额、均价、以及当时的估值口径（当时的 PE/PB 或当时那份研究的价值区间）。这把 `red-flags.md` 里「回购发生在明显高估区」从印象变成记录——每笔回购留下当时的估值坐标，今天可以直接对照。回购是否抵消了股权激励摊薄单独记，两者不能相抵后只报净数。

**并购**：记录金额、支付方式、当时给出的战略理由，以及事后回报评估的依据（被并购业务的收入与利润是否单独可见、有没有减值、承诺的协同有没有出现在分部数据里）。看不见就写看不见——并购后立刻并入大分部导致无法评估，本身是一条治理信息。

**分红**：与 `metric-playbook.md` 的股东回报覆盖率对账。派息率跳升时区分是盈利改善还是覆盖率被推高。

**新业务投入**：记录累计投入与当前状态。重点看止损纪律：连续投入多年、没有客户采用或单位经济证据的项目，管理层是否承认并退出。`red-flags.md`「第二增长曲线持续消耗研发和资本却没有采用证据」在这里能找到逐年的投入数字。

判定回报时，把每笔配置和 `metric-playbook.md` 的增量 ROIC 连起来：一段时间的增量资本投到哪里去了，回报是否兑现。逐笔记录的意义就是让这个问题有分子也有分母。

## 5. 不做的事

**不把兑现率映射成评语档位。** 计数比例是事实，「>80% 优秀 / <40% 不可信赖」是判断，而这个判断的分母取决于录了哪些承诺。一个可以靠少录几条软承诺改善的数字，不该看起来像评级。页面只呈现计数与未兑现清单。

**不做加权综合评分。** 诚信、能力、资本配置、治理四个维度不可比，加权和不携带比分项更多的信息，只是把判断藏进权重里。理由同 `business-model-playbook.md`「不要机械加权打总分」。

**不给管理层打星。** 要输出的是「哪几条没做到、哪几笔配置回报为负、下一期看什么」，而不是一个分数。

**不用非公开或需登录平台的员工评价充当证据。** 可公开搜索、可引用、可标注抓取时间的才进 `evidence`；其余只能作为方向校验，不写进结论。这与 `metric-playbook.md` 禁止把 LinkedIn 分类当官方数据是同一条规矩。
