# 商业模式与核心驱动指标手册

## 目录

1. 定义商业模式
2. 建立驱动树
3. 选择核心维度和指标
4. 按模式选取指标
5. 声明护城河与转折点
6. 判断商业模式是否变化
7. 推导长期投资结论

## 1. 定义商业模式

先用一句可证伪的话写清：`目标客户/用户 + 核心价值 + 付费者 + 收费方式 + 交付依赖 + 利润与现金来源`。

再回答以下问题：

- 谁使用、谁决策、谁付费？三者不同时分别说明。
- 客户为何选择、为何持续使用、为何不轻易切换？
- 公司按产品、订阅、使用量、交易额、广告、利差、保费、授权还是资产租金收费？
- 获客、供给、履约、售后和回款依赖哪些渠道、资产、员工、合作方或牌照？
- 规模扩大后，边际毛利、服务质量、资本占用和风险成本如何变化？
- 现金流用于维护现有业务、获取新客户、扩产、研发、并购还是返还股东？新增投入能否复制历史回报？

存在多种实质模式时分别建立子模型。例如“硬件销售 + 软件订阅”“自营零售 + 第三方平台”“放贷 + 支付服务”不能只按合并收入分析。标明各模式的收入、毛利、资产占用、现金流与战略作用。

## 2. 建立驱动树

按因果而非财报科目连接：

`关键投入/供给 → 获客/分发 → 活跃/交易/销量 → 定价/费率 → 收入 → 单位贡献 → 固定成本吸收 → 现金回收 → 再投资 → 下一轮供给和需求`

先写业务恒等式，再填数据。例如：

- 订阅收入 ≈ 平均付费客户 × 每客户经常性收入；期末 ARR 不能与期间收入混用。
- 平台收入 ≈ GMV/交易额 × 综合变现率 + 非交易收入；区分总额法与净额法。
- 零售收入 ≈ 门店/渠道数 × 单店客流 × 转化率 × 客单价；同店与开店增长分开。
- 工业收入 ≈ 出货量 × 价格/组合；订单、产能、良率和交付周期决定可实现性。
- 银行净利息收入 ≈ 生息资产 × 净息差；必须同时观察资金成本、信用损失和资本约束。

找出 1–3 个当前最紧约束。约束可能是需求、供给、获客成本、留存、产能、资本、牌照、内容、人才或现金，而不一定是收入增速。

## 3. 选择核心维度和指标

从下表选择 5–8 个真正决定飞轮的维度。每个维度保留 1–3 个指标；公司不披露时使用可复核代理指标，并降低置信度。

| 核心维度 | 要回答的问题 | 常见候选指标 |
| --- | --- | --- |
| 客户价值与需求 | 产品是否解决真实问题，需求深度是否提高？ | 活跃客户、销量、使用频次、渗透率、复购/续费、流失率、订单 |
| 获客与分发 | 新需求能否以可承受成本持续获得？ | 新增客户、自然流量、渠道结构、CAC、获客回收期、销售效率 |
| 供给与交付 | 供给是否充足、可靠且可扩展？ | 活跃供给、产能利用率、良率、交付周期、履约率、服务质量 |
| 定价与变现 | 公司能否获取所创造的价值？ | ARPU、单价/组合、take rate、广告价格、费率、折扣、净利差 |
| 单位经济与现金 | 每笔增量业务是否创造现金价值？ | 单位毛利、贡献利润、LTV/CAC、损失率、现金转换、维护性资本开支 |
| 规模效应与护城河 | 增长是否强化成本、网络、品牌、数据或切换优势？ | 留存、份额、成本曲线、双边流动性、研发复用、议价能力 |
| 再投资与组织 | 增量资本能否长期高回报复制？ | 增量 ROIC、研发产出、门店/产能回收期、人效、再投资率 |
| 脆弱点与外部约束 | 哪个依赖可能截断飞轮？ | 客户/平台/地区集中、监管资本、供应商集中、杠杆、技术替代 |

为每个入选指标建立指标卡：

| 字段 | 要求 |
| --- | --- |
| 因果作用 | 说明指标处于驱动树哪一环，以及如何影响收入、利润或现金 |
| 定义与口径 | 写清分子、分母、期间、总额/净额、是否公司自定义 |
| 属性 | 标明领先、同步或滞后指标，避免把结果指标当原因 |
| 基线 | 至少给出历史区间/均值、上次值和最新值 |
| 变化 | 同比、环比和多期趋势；按业务季节性选择合适比较 |
| 证据 | 原始来源、发布日期、披露频率和缺失限制 |
| 判定 | 改善/稳定/恶化、置信度、下一阈值及对估值的影响 |

不要机械加权打总分。先看约束指标，再看指标之间是否相互印证。例如用户增长但留存、ARPU 与现金贡献下降，不能仅凭用户数判断飞轮增强。

## 4. 按模式选取指标

先确定主要模式，再从相应行挑选指标。只保留能够进入驱动树的数据。

| 模式 | 需求/规模 | 留存/质量 | 变现/单位经济 | 供给/资本与主要约束 |
| --- | --- | --- | --- | --- |
| 订阅/SaaS | ARR、付费客户、席位、使用量 | NRR、GRR、logo churn、RPO | ARPU、毛利率、CAC 回收期、Rule of 40（辅助） | 销售效率、研发产出、SBC/摊薄、云成本 |
| 平台/市场 | GMV、订单、买卖双方、频次 | cohort 留存、复购、履约/取消率 | take rate、每单贡献利润、激励后收入 | 供给密度、匹配效率、补贴依赖、监管与多归属 |
| 支付/交易基础设施 | TPV、交易笔数、活跃商户/账户 | 留存、交易频次、支付成功率 | 净收入率、每笔成本、交易利润、欺诈/损失率 | 资金沉淀、渠道/网络依赖、合规资本 |
| 广告/内容 | DAU/MAU、时长、搜索/曝光量 | 用户/创作者留存、内容供给 | ARPU、CPM/CPC、广告负载、流量获取成本 | 推荐质量、内容成本、隐私与平台政策 |
| 消费品牌/零售 | 销量、客流、转化、同店、门店数 | 复购、会员活跃、退货、品牌搜索 | 客单价、价格/组合、折扣、单店贡献 | 库存周转、渠道库存、店效、开店回收期 |
| 工业/制造 | 出货量、订单、backlog、book-to-bill | 售后/服务占比、缺陷、交付 | 价格/组合、单位成本、毛利、贡献利润 | 产能利用率、良率、交付周期、维护/扩张 capex |
| 半导体/硬件 | 出货、ASP、设计导入、市场份额 | 产品周期、客户平台黏性 | 产品毛利、库存减值、研发回报 | 利用率、良率、库存天数、客户/代工集中 |
| 资源/周期品 | 产量、销量、储量/寿命 | 安全、品位、停机率 | 实现价格、单位现金成本、周期中枢利润 | 维持性 capex、产能纪律、杠杆、政策/地缘 |
| 药品/医疗/IP 授权 | 患者/处方、适应症、装机/使用 | 依从性、续约、临床/监管里程碑 | 净价格、毛利、授权费/版税 | 专利寿命、管线成功率、研发现金消耗、报销 |
| 银行/信贷 | 贷款/生息资产、存款、客户 | 核心存款留存、客户深度 | NIM、手续费、信用成本、风险调整收益 | NPL、拨备、CET1、流动性与期限错配；不用普通 FCF 估值 |
| 保险 | 保费、保单、续保率 | 持续率、退保率、赔付趋势 | 综合成本率、新业务价值、投资收益率 | 偿付能力、准备金质量、久期匹配、巨灾风险 |
| REIT/资产运营 | 出租面积、入住率、同店 NOI | 续租率、租金收缴 | 租金差、NOI margin、AFFO/股 | 资产质量、维护 capex、到期债务、利息覆盖 |

对混合模式分别选指标，再识别交叉补贴。例如低毛利硬件可能为高毛利订阅获客；只有在附着率、留存和生命周期贡献得到验证时，才认可该逻辑。

## 5. 声明护城河与转折点

指标选定之后才能谈护城河——护城河必须落在指标上，否则它只是一个形容词。

只声明 **1–3 条真正起作用的**护城河，写进 `businessModel.moat`。不要逐类打勾：品牌、转换成本、网络效应、规模成本、技术牌照五类里，多数公司真正具备的是一到两条，把五类都填一句话只会产出四条不存在的护城河。找不出任何一条，就诚实写「当前未识别出可验证的护城河」——那是一个重要结论，不是一个填不满的字段。

每条护城河必须回答四件事：

| 字段 | 要求 |
| --- | --- |
| 类型 | 五类之一，或「其他」并说明 |
| 机制 | 它作用在驱动树的**哪一环**。写位置，不写形容词——「客户迁移要重做集成，卡在获客与留存之间」是位置，「客户黏性强」不是 |
| 绑定驱动 | 至少一个已声明的驱动指标 ID。一条护城河若找不到任何驱动指标支撑，先怀疑它不存在，再考虑是不是缺了一个该建的指标 |
| 趋势 | 变宽 / 稳定 / 变窄 / 待验证。跨快照沿用同一条护城河的 ID，才能比出趋势 |

### 用参照类推导 breaker

每条护城河还要写出 `breaker`：**什么能摧毁它，以及在被摧毁之前能观察到什么前置信号。**

推导 breaker 的可靠办法是参照类推理，而不是想象：找出历史上处于同样结构位置的公司，看它们实际死于什么，再把那个死因映射到本公司的具体驱动上。

- 有用的写法：「同类公司的转换成本在客户完成一次系统换代时集体归零；对本公司，前置信号是新签客户中选择浅集成方案的比例上升」——它指向一个可观察量。
- 无用的写法：「这家公司会不会变成下一个 3Com」——类比本身既不是披露事实也不是可复算结果，它是纯推断，停在比喻上不产生任何可验证的东西。

参照类只用来生成假设。写进快照的是它推出的那个可观察信号，不是类比本身。若那个信号还没有对应指标，把它写成下一期的验证阈值。

## 6. 判断商业模式是否变化

每次评估都建立“最新变化清单”，至少覆盖：

1. 最新定期财报、业绩公告、电话会材料与监管文件。
2. 上次截止时间后全部重大公告、融资/回购/并购分拆、管理层与组织变化。
3. 产品、定价、渠道、客户合同、产能、供应链或技术路线的重要变化。
4. 主要竞争对手、行业供需、监管和替代技术的新证据。
5. 截至同一时点的参考股价与市场隐含预期。

把每条新证据映射到驱动树和指标卡，不另设与投资逻辑脱节的“新闻摘要”。按以下层级判断：

- **未变**：价值创造、交付与获取机制仍成立，指标在历史/季节性范围内。
- **参数变化**：价格、量、费率、成本、留存、利用率或资本效率变化，但因果链未改。
- **机制变化**：用户与付费者、收费方式、渠道、供给、交付或再投资方式改变；重建相关指标基线。
- **结构性变化**：监管、技术替代、控制权、重大交易、资本约束或依赖关系改变长期价值归属；重写估值框架。

除有明确合同、监管、交易或产品制度变化外，不以单一季度或单条媒体消息判定机制/结构改变。优先要求连续期数据、两个独立证据或领先指标与财务结果相互验证。若缺少最新指标，写“无法确认”，并列明需要的证据。

## 7. 推导长期投资结论

按以下顺序形成观点：

1. **持续性**：客户问题和付费意愿能否维持 5 年以上？
2. **经济性**：单位贡献、现金转换和周期归一化回报是否足够好？
3. **可复制性**：增量投入能否以合理回收期扩张，还是增长会稀释回报？
4. **防御性**：规模扩大是否增强护城河，关键依赖是否可替代？
5. **价值归属**：现金由股东获得，还是被客户、员工、平台、监管、债权人或控股股东攫取？
6. **价格**：当前估值隐含的核心指标路径是否比可验证基准更乐观？

输出长期投资建议时必须说明：

- 该公司属于高回报复利、稳定现金收割、周期均值回归、事件驱动，还是尚未验证的商业模式；
- 最强的 2–3 条商业模式证据和最脆弱的 1–2 个约束；
- 已声明的护城河中哪条在变宽、哪条在变窄，以及任何 breaker 的前置信号是否已经出现；
- 基准价值只纳入已验证的业务，未验证新业务作为概率加权可选项单列；
- 哪些核心指标达到什么阈值会提高/降低长期收入、利润率、资本回报或估值倍数假设；
- 结论是“适合长期持有候选”“观察等待验证”“仅适合周期/事件机会”还是“回避”，以及确信度和安全边际要求。

用下表把观点闭环到估值与行动：

| 核心指标/事件 | 最新状态 | 长期假设影响 | 估值影响 | 触发的观点/行动变化 |
| --- | --- | --- | --- | --- |
| 公司特定驱动 1 | | 收入/留存/份额 | 增长或倍数 | |
| 公司特定驱动 2 | | 毛利/单位经济 | 利润率或 FCF | |
| 公司特定驱动 3 | | 再投资/资本回报 | ROIC 或终值 | |
| 关键脆弱点 | | 风险与持续性 | 折价/安全边际 | |
