# Domain Docs

This repository uses a single domain context.

## Before exploring

- Read `CONTEXT.md` at the repository root.
- Read relevant decisions under `docs/adr/`.
- If either location is absent, proceed silently.

## Use the glossary vocabulary

Use terms exactly as defined in `CONTEXT.md` in issue titles, specifications, implementation plans, schemas, interfaces, and tests. Avoid synonyms listed under `_Avoid_`.

## Respect decisions

If proposed work conflicts with an existing ADR, surface the conflict explicitly instead of silently overriding the decision.
