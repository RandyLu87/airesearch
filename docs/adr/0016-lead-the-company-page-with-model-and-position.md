# 公司研究主页以商业模式和行业地位开篇，收缩快照对比

## 状态

已接受，2026-08-03。修正 ADR-0011 的一处预期。

## 背景

改版前的公司研究主页只有五块：页头四格、研究快照对比、公司特定驱动对比、估值与证据变化、历史研究报告。其中三块——占页面约六成篇幅——都在比较两份研究快照。

按 `AGENTS.md` 的第一句，本仓库「以商业模式、核心驱动和最新变化为主线」。主页上没有商业模式。快照里其实有：`summary.businessModel` 一句话、`sections[business-model]` 一段叙述、`driverMetrics` 里一条 `proxy-market-share`。主页一样都没渲染。

对比区的信息量则可以实测。逐字段 diff 2026-07-31 与 2026-08-03 两份快照：

- 标准指标 12 项，**12 项零变化**；
- 驱动指标 7 项，6 项零变化，1 项是新增（标记不可比较）；
- 投资立场、合理价值区间均未变；
- 唯一数值变化是参考价格 HK$127.4 → HK$125.9。

根因不是数据质量，是设计：标准指标全部锚在年报上，更新频率是一年一次，却被放在「每次研究都重画」的位置。同一财报周期内研究多少次，这张表都必然全零。

而按报告期展开的财报表恰好把这件事做对了——它一年内不变是应该的，展示的是趋势而非「零变化」。

## 决策

主页重排为八块，顺序即决策逻辑：

```
① 页头（立场 / 参考价格 / 合理价值）
② 商业模式（分部构成、因果链、交付依赖、现金引擎）
③ 行业地位（商业化份额 + 规模份额 + 背离）
④ 最新财报对比（同口径同比两列，纯 CSS 切换口径）
⑤ 核心驱动与最紧约束
⑥ 估值（价值桥 + 反向估值 + 升级提示）
⑦ 相对上次研究（压缩成一条）
⑧ 历史研究报告
```

**标准指标对比表删除。** 它的内容被 ④ 完全覆盖且覆盖得更好，保留只会制造两套互相矛盾的叙事（一个说「FY2025 收入 77.59，变化 0」，一个说「FY2021→FY2025 从 89.9 降到 77.6」）。

**驱动对比并入驱动卡片**，每张卡显示「上次 → 本次」加趋势与阈值，不再单列表格。

**`driverChanges`、立场与估值变化压进 ⑦ 一块**。

同一套结构化区块也加进研究报告页，位置在摘要之后、叙述章节之前。

### 与 ADR-0011 的关系

ADR-0011 写过「公司研究主页上的研究快照对比会逐步变得有信息量……改善从下一份快照开始」。这条预期只在驱动指标那一层成立，本 ADR 保留了那一层（换了呈现位置）并保留了 `driverChanges` 的展示位。**被推翻的是标准指标对比表**：它的更新频率由财报周期决定，延续性规则再怎么执行也不会让它在同一财报周期内产生信息。ADR-0011 的驱动延续机制本身不受影响。

## 备选方案

**全部删除对比区。** 最干净。否决原因：`driverChanges` 会失去展示位，而 ADR-0011 刚建立这个机制正是为了防止驱动集被静默替换。

**保留完整对比区但默认折叠。** 改动最小，无 ADR 冲突。否决原因：那张十二项全零的表仍然存在，只是藏起来；它与 ④ 的重复叙事会让读者对不上号。

**先只改渲染，不动 schema。** 今天就能出效果。否决原因：商业模式与行业地位在旧 schema 里只是自由文本和某家公司自选的驱动指标，换一家公司就不保证有——「适配所有公司」会退化成运气好。

## 后果

- 首次研究一家新公司的成本上升：`businessModel` 与 `marketPosition` 是必填块，取不到数据也必须写明 `status: "unavailable"` 与原因。这是刻意的，缺口从此可见。
- 主页变长了。分块顺序按决策逻辑排列，读者可以在任意一块停下。
- 历史 1.0.0 快照的主页与报告页仍按旧结构渲染。见 ADR-0017 对版本化契约的说明。
